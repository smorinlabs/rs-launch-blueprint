# Design Specifications

Design specifications are **normative** documents specifying what to build and
how a subsystem must behave before or during implementation (`F355`).

## Conventions

- **Filename:** `NNNN-kebab-title.md` (zero-padded, sequential, starting at `0001`).
- **Header fields:** `Status`, `Created`, and `Applies to`.
- **Status lifecycle:** `Draft` -> `Proposed` -> `Accepted` ->
  (`Implemented` | `Superseded` | `Withdrawn`).
- Cross-link motivating explorations in `docs/research/` and resulting decisions
  in `docs/adr/`. Register new specs in [SUMMARY.md](../SUMMARY.md) and the
  index below.
