# `new-rust-project` Skill

`new-rust-project` automates creating a fresh Rust repository from
`smorinlabs/rs-launch-blueprint`, stamping all crate, binary, workflow, and
documentation tokens via Template Press, and verifying every workspace gate.

- **Skill instructions:** `.claude/skills/new-rust-project/SKILL.md`
- **Installation guide (project + global):** `.claude/skills/new-rust-project/README.md`
- **Post-initialization checklist:** [`docs/PROJECT_SETUP.md`](../PROJECT_SETUP.md)

When a child repository is stamped, this page is automatically replaced with a
provenance record pointing to `press/press-receipt.toml`.
