# R60 evidence snapshots — the single registry of what each snapshot is and where it came from.
#
# Every file in this directory is an input to an R60 evidence script. The scripts
# read ONLY these files plus files committed elsewhere in this repository, so they
# rerun to the same result from a clean checkout of the commit that carries them.
#
# Columns, '|'-separated:
#   1 sha256      sha256 of the snapshot file as committed here
#   2 file        file name, relative to this directory
#   3 kind        raw   = a single file published at a pinned URL
#                 crate = a file inside a crates.io tarball pinned by version and checksum
#                 local = a file with no public remote; the committed copy is the evidence
#                         of record and the origin is a git object in a private repository
#                 self  = an object in this repository's own git history
#   4 origin      the pinned URL (raw), the tarball URL (crate), or the git ref (local/self)
#   5 inner       path inside the tarball (crate), path inside the origin repository
#                 (local/self), or '-' (raw)
#   6 checksum    for kind=crate, the sha256 crates.io records for that tarball; else '-'
#
# `r60-snapshot-provenance-r3.sh` re-derives columns 1 from columns 3-6 over the
# network. `r60-standard-pin-r3.sh` and `r60-preservation-diff-r3.sh` verify
# column 1 offline before reading any snapshot.
#
# The `.txt` suffix on source files is deliberate: it keeps this run directory free
# of anything a build tool would treat as Rust, Python or TypeScript source, which
# is what `r60-preservation-diff-r3.sh` check C5 asserts.
#
